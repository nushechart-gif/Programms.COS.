- В ОП.08 специальности 09.02.12 сводная таблица указывает дифференцированный зачёт, а тематический план — экзамен. В существующем КОС сохранён дифференцированный зачёт по сводной таблице.
- В ПМ.03 специальности 09.02.11 для МДК 03.02 в сводной таблице указано 168 часов, в тематическом плане — 176. Исходная программа сохранена; названия тем и формы контроля новых КОС взяты из тематического плана.
